Q-A — Admin set assignment update SQL

This idempotent additive migration adds the admin-only option to repeat a completed same-grade set or assign the next unused questions after a student finishes.

Run it in the existing SmartPle project’s SQL Editor after the Q-A schema and admin authorization are in place. Fresh setup already includes this feature; no need to rerun the full setup.

Safe scope: this changes only Q-A assignment metadata and a guarded RPC. It does not change Auth accounts, profile rows, question content, or the existing daily target rules. A paused student must first be given a positive target.
Tip: if clipboard access is blocked, click inside the SQL box, press Ctrl+A (or ⌘A), then Ctrl+C (or ⌘C).
