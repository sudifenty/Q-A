LIVE CONNECTION

Connect to your Q-A Supabase project

Use the project URL and publishable/anon key for this standalone Q-A app. These are client-side values; do not enter a service-role secret. For live Supabase mode, serve this file from an http(s) site; some browsers block API requests from file:// URLs.

Database setup SQL (copy into Supabase SQL Editor)

Run the migration and question-bank seed in order. The file cannot safely execute schema changes from the browser; copy the SQL into the existing project’s SQL Editor.
